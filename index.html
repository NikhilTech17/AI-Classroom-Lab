PROJECT INFORMATION

About AI Classroom Lab

Understand what this project does, how it works and what it demonstrates.

AI

AI-POWERED STUDENT WORKSPACE

One place for learning, creating and experimenting with AI.

AI Classroom Lab is a single-page educational web application that brings together ten practical AI tools for students. Users can enter their own information, connect their own Gemini API key and use the tools directly from the browser.

01

What it does

The project provides tools for resume building, notes, presentations, mind maps, Google Sheets, quizzes, doubt solving, flashcards, study planning and OCR-based note summarization.

02

How it works

The frontend collects user input. JavaScript sends prompts to the Gemini API, receives the AI response and dynamically displays the result in the selected tool.

03

Built for learning

This project demonstrates practical use of HTML, CSS, JavaScript, APIs, JSON, browser-side AI integration, GitHub and static web deployment.
